# Code of Conduct

This is a small technical project. The expectations are short and they are not negotiable.

Be straightforward and be civil. Argue about the code, the design and the evidence, never about the person. Assume the other person is competent and acting in good faith until you have real reason to think otherwise, and say what that reason is if you get there.

Harassment, personal attacks, discriminatory language, and deliberately wasting people's time are not welcome here. Neither is bringing an argument from somewhere else into this repository.

If you are reviewing, be specific. "This is wrong" helps nobody. Say what is wrong, why it matters, and what you would accept instead. If you are being reviewed, remember that a request for changes is about the patch and not about you.

If someone asks you to stop doing something, stop. Sort out whether it was fair afterwards, not during.

## Reporting

Report problems to the repository owner through [private vulnerability reporting](https://github.com/tamnd/mojo.windows/security/advisories/new), which is the only private channel this repository has, or by direct message on GitHub. Reports are handled quietly. Outcomes range from a private word to a permanent ban, depending on what happened.

Maintainers are held to this the same as everyone else, and more visibly.
